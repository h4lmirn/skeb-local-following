# Skeb Local Following

Skebのフォロー中一覧に、保存したクリエイターの情報を表示するChrome拡張です。
募集状態、おまかせ金額、作品例を、自分の端末に保存します。
情報は自分で保存したときに記録し、自動では更新しません。

この拡張は、株式会社スケブやSkeb公式とは関係のない非公式の道具です。
一覧に出るのは、最後に保存したときの情報です。
依頼する前に、クリエイターページで今の募集状態と金額を確かめてください。

## できること

- 保存したクリエイターの募集状態とおまかせ金額を、一覧で見る
- 作品例の小さな画像を、最大3点見る
- 情報を保存した日時を見る
- 自分で作ったフォルダに分けて、一覧を絞り込む
- 作品例をぼかす、表示するリクエスト種類を選ぶ
- 1人分の保存を解除する、保存した全員の情報を消す
- 保存情報、フォルダ、表示設定をファイルに書き出す、読み戻す

作品例はカードの幅に合わせて表示します。
横長のカードでは、画像を引き伸ばしすぎないように幅を制限します。

## いるもの

- Google Chrome
- Skebのアカウント
- このリポジトリのファイル

ビルドや、追加のライブラリのインストールは要りません。

## 始め方

### Chromeに入れる

1. GitHubの「Code → Download ZIP」からファイルをダウンロードします。
2. ZIPを開き、フォルダを普段使う場所に置きます。
3. Chromeで `chrome://extensions` を開きます。
4. 右上の「デベロッパー モード」をオンにします。
5. 「パッケージ化されていない拡張機能を読み込む」を押します。
6. `manifest.json`が入っているフォルダを選びます。

Gitを使う場合は、ダウンロードの代わりに次を実行できます。

```sh
git clone https://github.com/h4lmirn/skeb-local-following.git
```

読み込んだフォルダは、その場所に残してください。
あとで別の場所から読み込むときは、「別のフォルダへ移すとき」の手順を使います。

### クリエイターを保存する

1. Skebにログインします。
2. 保存したいクリエイターのトップページを開きます。
3. 右下の「この人を一覧用に保存」を押します。
4. クリエイター名と「一覧用情報をこの端末に保存しました」という通知を確かめます。

保存したあとは、次のボタンが出ます。

| ボタン | すること |
| --- | --- |
| 一覧用情報を更新 | 今のページに表示されている情報で、保存内容を更新します |
| 保存解除 | そのクリエイターの保存情報を消します |

ページを開いただけでは保存しません。
作品ページではなく、クリエイターのトップページで操作してください。

### フォロー中一覧で見る

Skebの「フォロー中のクリエイター」を開きます。
URLは次の形です。

```text
https://skeb.jp/@あなたのユーザーID/following_creators
```

保存したクリエイターのカードに、次の情報が加わります。

- 「最終閲覧時：募集中」または「最終閲覧時：停止中」
- ジャンル別のおまかせ金額
- 作品例の画像（最大3点）
- 保存した日時

保存していないクリエイターには、募集状態や金額、作品例を追加しません。

## たとえば、こう使います

気になるクリエイターのページを開き、「この人を一覧用に保存」を押します。
あとでフォロー中一覧を開くと、保存した募集状態や金額を見返せます。

その後、クリエイターが金額を変えても、一覧の保存情報は自動では変わりません。
ページをもう一度開き、「一覧用情報を更新」を押すと更新できます。

フォルダ分けだけを使うこともできます。
プロフィール情報を保存していない人も、フォルダに分けられます。
その場合、募集状態や金額は一覧に追加されません。

## フォルダで分ける

1. クリエイターページ右下の「＋フォルダ作成」を押します。
2. 「依頼候補」など、30文字以内の名前を入れます。
3. フォロー中一覧の上部にある「フォルダ」で、表示するフォルダを選びます。

プロフィールで新しいフォルダを作ると、そのクリエイターも同時に分類します。
すでにあるフォルダは、プロフィール右下の選択欄から選べます。
一覧の各カードにある選択欄からも変更できます。

フォルダは、次の場所でも作れます。

- Chromeの拡張アイコンを押して開く画面の「ローカルフォルダ」
- フォロー中一覧の上部にある「ローカル整理」

一覧は、すべての人、未分類の人、選んだフォルダの人に絞り込めます。
対象外のカードは枠ごと隠し、残ったカードを詰めて並べます。
フォルダ名と分類は、この端末だけに保存します。

## 表示を変える

Chromeのツールバーで、Skeb Local Followingの拡張アイコンを押します。

| 設定 | 変わること |
| --- | --- |
| 一覧の作品例をぼかす | 作品例のぼかしをオン、オフにします |
| 表示するリクエスト種類 | 一覧におまかせ金額を出す種類を選びます |

作品例のぼかしは、はじめはオンです。
センシティブと判定された作品例は、設定をオフにしてもぼかします。
リクエスト種類の選択肢は、保存したクリエイターの情報から作ります。
金額は、非表示にした種類を除き、1枚のカードに最大4件表示します。

## 保存した情報を残す、消す

### バックアップを作る

拡張アイコンを押し、「バックアップを書き出す」を選びます。
保存情報、フォルダ、分類、表示設定をJSONファイルに書き出します。
JSONは、あとでこの拡張に読み戻せるファイル形式です。

読み戻すときは「バックアップを読み込む」を押し、書き出したファイルを選びます。
今ある情報に、ファイルの内容を追加します。
同じクリエイターの情報や分類、同じ表示設定は、読み込んだ内容で更新します。
フォルダ名は、今あるものと読み込んだものをまとめます。

### 保存した情報を消す

1人分だけ消すときは、そのクリエイターのページで「保存解除」を押します。

全員分を消すときは、拡張アイコンを押して次の順に操作します。

1. 「保存したクリエイター情報を削除」を押します。
2. 赤い「本当に削除する（元に戻せません）」を押します。

この操作で消えるのは、保存したクリエイター情報です。
フォルダ、分類、表示設定は残ります。
消したクリエイター情報は元に戻せません。
残しておきたい場合は、先にバックアップを書き出してください。

## 新しい版に入れ替える

### 同じフォルダで更新するとき

1. 新しいファイルを、今使っているフォルダへ入れます。
2. `chrome://extensions` を開きます。
3. Skeb Local Followingのカードにある更新ボタンを押します。
4. 開いているSkebページを再読み込みします。

同じフォルダの拡張を更新する場合は、保存情報を引き継ぎます。

### 別のフォルダへ移すとき

別のフォルダから読み込むと、Chromeは別の拡張として扱うことがあります。
保存情報は自動で引き継がれないため、バックアップで移します。

1. 旧版を消さず、旧版と同じフォルダへ新版のファイルを上書きします。
2. `chrome://extensions` で旧版の更新ボタンを押します。
3. 旧版の拡張アイコンを押し、「バックアップを書き出す」を選びます。
4. 新しいフォルダから拡張を読み込みます。
5. 新版で「バックアップを読み込む」を押し、書き出したJSONファイルを選びます。
6. 保存人数とフォルダを確かめてから、旧版を削除します。

バックアップに対応していない旧版でも、先に同じ場所で更新すれば書き出せます。
旧版を先に削除すると、旧版の保存情報を読み出せなくなります。

## 保存するものと通信

保存するものは、次のとおりです。

- SkebのユーザーIDと表示名
- プロフィールのURL
- 保存したときの募集状態
- ジャンルとおまかせ金額
- 表示済みの作品ページのURL
- 表示済みの作品画像のURL（最大3件）
- 保存日時
- 自分で作ったフォルダ名と、クリエイターの分類
- 作品例のぼかしと、金額を表示する種類の設定

情報は、この端末の `chrome.storage.local` に保存します。
ブラウザの同期用の保存先や、開発者のサーバーには送りません。
画像ファイルそのものは保存しません。

作品例を一覧に表示するときは、ブラウザが画像の配信元へ通信することがあります。
通常のウェブ画像と同じように、保存した画像URLから読み込むためです。

バックアップは、自分で書き出したときだけファイルに保存します。
読み込むのは、自分で選んだJSONファイルだけです。
バックアップの内容を、開発者のサーバーへ送ることはありません。
詳しくは[プライバシーポリシー](PRIVACY.md)を参照してください。

## Chromeに許可すること

| 許可 | 用途 |
| --- | --- |
| `storage` | クリエイター情報、フォルダ、表示設定を端末内に保存します |
| `https://skeb.jp/*`での動作 | 保存ボタンと一覧情報を出し、画面に表示済みの内容を読みます |

Cookie、閲覧履歴、認証トークン、通信内容を読み取る権限は求めません。
解析やトラッキングの機能もありません。

## うまく動かないとき

### 保存ボタンが出ない

- クリエイターのトップページを開いているか確かめます。作品ページでは出ません。
- `chrome://extensions` で、この拡張がオンか確かめます。
- 更新した直後は、拡張の更新ボタンを押してからSkebページも再読み込みします。

### 保存しても一覧に出ない

- 「フォロー中のクリエイター」を開いているか確かめます。
- そのクリエイターが、今のページに表示されているか確かめます。
- フォルダの絞り込みや並び順で、対象の人が見えなくなっていないか確かめます。
- 拡張アイコンを押し、保存人数を確かめます。

### 情報が古い

クリエイターページをもう一度開きます。
「一覧用情報を更新」を押してください。
この拡張は、保存した情報を自動では更新しません。

### 画像が出ない、表示が崩れる

作品が非公開になったり、画像URLの期限が切れたりすると、画像が出なくなります。
Skebのページ構造が変わると、拡張が動かなくなることもあります。

不具合は[GitHub Issues](https://github.com/h4lmirn/skeb-local-following/issues)へ報告してください。
次の情報があると、起きたことを確かめやすくなります。

- 問題が起きたページのURL
- ブラウザ名
- 拡張のバージョン
- 問題がわかるスクリーンショット

スクリーンショットからは、アカウント情報や非公開の情報を隠してください。

## 使う前に知っておくこと

募集再開を見張ったり、プロフィールを自動で巡回したりする機能はありません。
保存していない人の募集状態や金額も表示しません。
ブラウザの拡張データを消すと、保存情報も失われます。

作品の権利は、それぞれのクリエイターにあります。
この拡張を入れても、作品を利用する許可を得たことにはなりません。
Skebの利用規約、各種ガイドライン、クリエイターの意思を尊重して使ってください。

- [Skeb](https://skeb.jp/)
- [Skeb利用規約](https://skeb.jp/terms)

## 中のしくみ

開発するときに見るファイルは、次のとおりです。

```text
skeb-local-following/
├── manifest.json  # Chrome拡張の設定（Manifest V3）
├── content.js     # ページの読み取り、保存、一覧への表示
├── styles.css     # Skebページに加える表示の見た目
├── popup.html     # 拡張アイコンから開く画面
├── popup.js       # 設定、バックアップ、保存情報の削除
├── popup.css      # 設定画面の見た目
├── PRIVACY.md     # プライバシーポリシー
└── LICENSE        # MIT License
```

ページの読み取りと保存は、次のように作っています。

- `fetch`や`XMLHttpRequest`で、SkebページやAPIを直接取得しません。
- 非表示の`iframe`などで、プロフィールを自動で読み込みません。
- プロフィール情報は、保存や更新のボタンを押したときだけ記録します。
- フォルダ分けは、作成や選択の操作をしたときだけ記録します。
- 作品例は、ページに表示済みの画像URLを保存します。
- 表示には`textContent`とDOM APIを使い、読み取った文字列をHTMLとして実行しません。

通信処理の変更を確認するときは、たとえば次の検索を使えます。

```sh
rg 'fetch|XMLHttpRequest|chrome\.cookies|webRequest' --glob '*.js' .
```

これは、該当する名前を使った処理を探すコマンドです。
検索だけで、すべての通信の有無を確かめられるわけではありません。
