# Skeb Local Following

Skebで自分が選んだクリエイターの情報を端末内に保存し、フォロー中一覧を見やすくする非公式Chrome拡張です。

クリエイターページで明示的に保存した場合だけ、表示済みの募集状態、おまかせ金額、作品例を記録します。プロフィールの自動巡回、Skeb APIへの直接アクセス、外部サーバーへのデータ送信は行いません。

> [!IMPORTANT]
> この拡張は株式会社スケブおよびSkeb公式とは関係のない非公式ツールです。表示内容は最後にプロフィールを閲覧して保存した時点のものであり、現在の募集状況や金額を保証しません。リクエスト前に必ずクリエイターページで最新情報を確認してください。

## Features

- 選択したクリエイターだけを手動保存
- 最終閲覧時の募集状態をフォロー中一覧に表示
- ジャンル別のおまかせ金額を表示
- 表示済み作品のサムネイルを最大3点表示
- 作品例はカード幅を使って見やすく表示し、横長レイアウトでは最大幅を設けて過度な引き伸ばしを防止
- クリエイターごとに自分のフォロー状態を端末内へ登録し、他のユーザーの一覧でも判別
- 任意のローカルフォルダを作成し、クリエイターを分類・絞り込み
- 情報の最終閲覧日時を表示
- サムネイルをぼかすプライバシー設定
- クリエイター単位の保存解除
- 全保存情報の一括削除
- 外部サーバー、解析、トラッキングなし

## How to use

### 1. Install

1. このリポジトリをダウンロードまたはcloneします。
2. ChromeまたはArcで `chrome://extensions` を開きます。
3. 画面右上の「デベロッパー モード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. `skeb-local-following` フォルダを選択します。

### 2. Save a creator

1. Skebへログインします。
2. 保存したいクリエイターのトップページを通常どおり開きます。
3. 画面右下の「この人を一覧用に保存」を1回押します。
4. 「一覧用情報をこの端末に保存しました」という通知を確認します。

保存後、同じ場所には次の操作が表示されます。

- 「一覧用情報を更新」：現在表示されている情報で上書きします。
- 「保存解除」：そのクリエイターを一覧保存から外します。

プロフィールを開いただけでは保存されません。

同じ操作欄のフォルダ選択で、そのクリエイターを既存のローカルフォルダへ分類できます。「＋フォルダ作成」では新しいフォルダを作り、そのクリエイターを同時に分類します。フォルダ分類はプロフィール情報を保存していないクリエイターにも使用できます。

### 3. View the enhanced following list

Skebの「フォロー中のクリエイター」一覧を開きます。通常のURLは次の形式です。

```text
https://skeb.jp/@あなたのユーザーID/following_creators
```

保存済みクリエイターのカードに以下が追加されます。

- 「最終閲覧時：募集中」または「最終閲覧時：停止中」
- ジャンル別のおまかせ金額
- 作品例のサムネイル最大3点
- 最終閲覧日時

未保存のクリエイターには何も追加されません。

### 4. Configure or delete saved data

ブラウザのツールバーから拡張アイコンを押します。

- 「一覧の作品例をぼかす」で、サムネイルのぼかしを切り替えられます。
- 「表示するリクエスト種類」で、一覧に金額を表示する種類を選べます。項目は保存済みクリエイターから自動生成されます。
- 「保存情報をすべて削除」を押し、続けて赤い確認ボタンを押すと全件削除できます。

一括削除は元に戻せません。個別に削除したい場合は、対象クリエイターのプロフィールで「保存解除」を押してください。

### 5. Record creators you follow

フォロー中ページの各クリエイターカードにある「自分のフォローに登録」を押します。登録済みのカードには「✓ 自分もフォロー中」と表示され、もう一度押すと登録を解除できます。

この記録はページ単位ではなくクリエイター単位です。自分や他のユーザーのフォロー中ページで同じ登録状態が表示されます。

### 6. Use local folders

1. 拡張ポップアップ、またはクリエイタープロフィール右下の「＋フォルダ作成」で任意のフォルダを作成します。
2. プロフィール右下、またはフォロー中ページの各カードにあるプルダウンでフォルダを割り当てます。
3. ページ上部の「フォルダ」から、すべて・未分類・各フォルダで絞り込みます。

フォロー記録、フォルダ名、フォルダへの割り当てはすべて `chrome.storage.local` に保存されます。

## Updating the extension

ファイルを更新しただけでは、インストール済みの拡張へ反映されない場合があります。

1. `chrome://extensions` を開きます。
2. Skeb Local Followingのカードにある更新ボタンを押します。
3. 開いているSkebページを再読み込みします。

## Data and privacy

保存される情報は次のとおりです。

- SkebのユーザーIDと表示名
- プロフィールURL
- 最終閲覧時の募集状態
- ジャンルとおまかせ金額
- 表示済み作品ページURL
- 表示済みサムネイルURL（最大3件）
- 保存日時
- ユーザーが個別登録した自分のフォロー中クリエイターID一覧
- ローカルフォルダ名とクリエイターへの割り当て

情報は `chrome.storage.local` に保存され、ブラウザの同期領域や開発者のサーバーには送信されません。画像ファイル自体は保存しません。詳しくは[PRIVACY.md](./PRIVACY.md)を参照してください。

## Permissions

この拡張が要求する権限は最小限です。

| 権限 | 用途 |
| --- | --- |
| `storage` | ユーザーが選んだクリエイター情報、フォロー記録、ローカルフォルダ、表示設定を端末内に保存するため |
| `https://skeb.jp/*` | Skebページ上に保存ボタンと一覧情報を表示し、ユーザー操作時に表示済みDOMを読むため |

Cookie、閲覧履歴、認証トークン、通信内容を読み取る権限は要求しません。

## Safety design

- `fetch`、`XMLHttpRequest`によるSkebページやAPIの取得を行いません。
- hidden iframeなどを使ったプロフィールの自動読み込みを行いません。
- バックグラウンド巡回や募集再開監視を行いません。
- プロフィール情報は「この人を一覧用に保存」を押した場合だけ保存します。フォロー記録とフォルダ分類も、それぞれのボタンや選択欄を操作した場合だけ保存します。
- 画像本体ではなく、プロフィールに表示済みのサムネイルURLだけを保存します。
- DOMへの表示には `textContent` とDOM APIを使用し、取得文字列をHTMLとして実行しません。

## Troubleshooting

### 保存ボタンが表示されない

- クリエイターのトップページか確認してください。作品ページでは表示されません。
- `chrome://extensions` で拡張が有効か確認してください。
- 拡張を更新した直後は、拡張管理画面で更新してからSkebページも再読み込みしてください。

### 保存しても一覧に表示されない

- 「フォロー中のクリエイター」一覧を開いているか確認してください。
- 対象クリエイターが現在表示されているページ内にいるか確認してください。
- 絞り込みや並び順を変更している場合は、対象が一覧内に含まれているか確認してください。
- Skeb Local Followingのポップアップに表示される保存人数を確認してください。

### 情報が古い

本拡張は自動更新しません。クリエイターページを再度開き、「一覧用情報を更新」を押してください。

### レイアウトが崩れる／表示されなくなった

Skeb側のDOM構造変更により動作しなくなることがあります。再現するURL、ブラウザ名、拡張バージョン、スクリーンショットを添えてGitHub Issuesへ報告してください。スクリーンショットにアカウント情報や非公開情報が含まれないよう注意してください。

## Development

ビルド工程や外部依存はありません。ファイル構成は次のとおりです。

```text
skeb-local-following/
├── manifest.json  # Manifest V3設定
├── content.js     # DOMの読み取り、保存、一覧表示
├── styles.css     # Skebページへ追加するUI
├── popup.html     # 拡張ポップアップ
├── popup.js       # 設定と一括削除
├── popup.css      # ポップアップのスタイル
├── PRIVACY.md     # プライバシーポリシー
└── LICENSE        # MIT License
```

動作確認時は、JavaScriptから次のような追加通信処理が増えていないことを確認してください。

```sh
rg 'fetch|XMLHttpRequest|chrome\.cookies|webRequest' .
```

## Known limitations

- SkebのDOM構造変更に影響を受けます。
- 未保存のクリエイター情報は表示しません。
- 保存情報は現在値ではなく、手動保存した時点のスナップショットです。
- サムネイルURLの期限切れや作品の非公開化により、画像が表示されなくなる場合があります。
- ブラウザの拡張データを消去すると保存情報も失われます。
